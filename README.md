## About

Small exercises and mini projects across different languages and topics, organized by language. Current focus is backend development and machine learning, along with the math behind it, but anything I want to learn or try goes here.

## Structure

| Folder | What's inside |
| ------ | ------------- |
| `python/` | Python exercises, ML and math experiments |
| `go/` | Go fundamentals and backend practice |

Each folder contains small, self-contained exercises, one per topic.

## Note

Code here is exploratory, so expect it to be messy or unfinished. Projects I finish and want to showcase get their own repo.
